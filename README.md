# Felt

**Дневник того, как ощущался день.** Проект команды для Genesis Hackathon, трек ArtTech 2026 (кейс «Make the Invisible Visible»).

Прототип: **https://diarythefelt.vercel.app**

Вы пишете пару абзацев о дне, добавляете фотографии и песню. Felt читает всё это и проявляет страницу дневника: палитра берётся из ваших снимков, свет зависит от времени суток в тексте, склейки в мини-фильме идут ровно в такт песне. День получает название и папку, а папку можно скачать целиком. Через полгода открываешь запись и снова попадаешь в тот день, а не просто смотришь на фотографии.

---

## Что умеет

- **Запись дня.** Свободный текст, можно надиктовать голосом. Пока вы пишете, Mood‑meter уже показывает, каким выходит день.
- **Фото.** От 1 до 12 снимков. Из каждого браузер достаёт палитру, яркость, тип освещения и «центр тяжести» кадра.
- **Песня.** Свой аудиофайл, поиск по каталогу (iTunes Search API, 30‑секундное превью) или ссылка на Spotify / YouTube / SoundCloud / Apple Music / Bandcamp. Файл и превью мы анализируем сами: темп, тональность, энергия. Если по ссылке звук недоступен, темп можно отстучать.
- **Проявка.** Движок собирает дизайн из пяти стилей (плёнка, журнальный разворот, коллаж, тихий минимализм, абстрактный сигнал) и подстраивает под день палитру, шрифт, фактуру, свет, генеративный слой и ритм.
- **«Почему так выглядит».** У каждой страницы есть разбор: какое слово, какой снимок и какой такт песни привели к какому решению.
- **Папка дня.** Название из 3–7 слов, ZIP с `entry.txt`, `memory.svg`, `memory.json`, фотографиями, песней (или ссылкой на неё) и голосовой заметкой, если она записана.
- **Архив.** Лента дней, календарь настроений, страница года и сторис‑рекапы.
- **Felt AI** (по желанию). Помогает подобрать слова, предложить песню, придумать название. Без ключей ИИ приложение работает полностью, названия тогда придумывает локальный движок.

## Как устроена проявка

```
текст ──► analysis/text.ts   ─┐  настроение, время суток, сезон, погода, мотивы
фото  ──► analysis/image.ts  ─┼► engine/design.ts ──► MemoryDesign ──► страница, рил, постер, папка
песня ──► analysis/audio.ts  ─┘  BPM, тональность, энергия, огибающая
```

`engine/design.ts` детерминированный: один и тот же день с теми же входными данными всегда проявляется одинаково (seed считается от id и текста). Каждое решение записывается в `explanations`, оттуда берётся разбор на странице.

Несколько правил, чтобы было понятно, о чём речь:

- Минор делает второй цвет палитры соседним и приглушённым, мажор при высокой энергии ставит его через круг для контраста.
- Длина склейки подбирается из 1, 2, 4 или 8 ударов так, чтобы попасть в целевую длительность кадра. Чем энергичнее день, тем короче кадр.
- Ностальгия выцветает фото, добавляет зерно и бумагу. Напряжение сливает цвет в монохром и включает моноширинный шрифт.
- Ночь в тексте, тёмные снимки и минор вместе дают тёмный фон.

## Стек

| Слой | Что используем |
|---|---|
| Фреймворк | Next.js 16 (App Router), React 19, TypeScript |
| Анимация | `motion`, Canvas 2D, CSS |
| Валидация | `zod` |
| База | PostgreSQL через `postgres` (на проде), запасные режимы: Vercel Blob или локальный файл |
| Хранилище медиа | Vercel Blob или локальная папка |
| Декодирование JPEG на сервере | `jpeg-js` (для демо‑дней) |
| Шрифты | Fraunces, Inter Tight, Bricolage Grotesque, JetBrains Mono, Onest, Caveat (`@fontsource`) |
| Браузерные API | Web Audio API, Web Speech API (диктовка), MediaRecorder (голосовая заметка) |
| ИИ (необязательно) | Groq (gpt‑oss), Google Gemini, Mistral, xAI Grok, Anthropic Claude с автоматическим переключением |
| Хостинг | Vercel |

Анализ звука (FFT, спектральный поток для темпа, профили Крумхансла для тональности), анализ фото (k‑means в OKLab) и сборщик ZIP написаны в проекте без сторонних библиотек.

## Запуск локально

Нужен Node.js 22.6 или новее.

```bash
git clone https://github.com/Hikal74/genesis-arttech.git
cd genesis-arttech
npm install
npm run dev
```

Откройте http://localhost:3000. Без переменных окружения база пишется в локальный файл, медиа сохраняются в локальную папку, ИИ выключен. Демо‑дни подгружаются сами.

Проверки движка:

```bash
npm test
```

Тесты проверяют, что темп меряется по сигналу, что анализ фото различает тёплое и холодное, что названия укладываются в 3–7 слов и не меняются от запуска к запуску, что разные дни дают разные стили, что ссылки на музыку превращаются в официальные плееры и что папка дня собирается в рабочий ZIP.

Сборка для продакшена:

```bash
npm run build && npm start
```

## Переменные окружения

Все необязательные. Шаблон лежит в `.env.example`.

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | PostgreSQL для записей |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob для фото, аудио и голосовых заметок |
| `GROQ_API_KEY`, `GROQ_MODELS` | основной провайдер ИИ |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | запасной провайдер |
| `MISTRAL_API_KEY`, `MISTRAL_MODEL` | запасной провайдер |
| `XAI_API_KEY`, `XAI_MODEL`, `FELT_PAID_AI=on` | Grok, включается отдельным флагом |
| `ANTHROPIC_API_KEY`, `CLAUDE_MODEL` | Claude |
| `FELT_CHAT_SYSTEM_PROMPT` | свой системный промпт для чата |

## Структура

```
src/
  app/                 страницы (/, /new, /m/[id], /archive, /year, /recap) и API
    api/memories/      создание, правка, удаление дня, выгрузка папки
    api/upload/        загрузка медиа
    api/songs/search/  поиск песен
    api/ai/            чат Felt AI
  components/          интерфейс: Composer, MemoryView, Archive, MoodCalendar, Flipbook…
  lib/
    analysis/          текст, фото, звук, настроение
    engine/            дизайн‑движок, пресеты, музыка, шрифты, названия
    server/            база, хранилище, проявка, ИИ, ZIP, демо‑данные
    tests/             тесты движка
public/demo/           фото и треки для демо‑дней
```

## Как мы это делали

Интерфейс (страницы, компоненты, стили, анимации) мы собирали вместе с Claude. Серверную часть, движок правил и анализ текста, фото и звука писали руками. ИИ внутри самого продукта нужен только для названий, строки атмосферы, подсказок песен и чата. Сам дизайн дня считает наш движок по нашим правилам, генеративные модели картинок не используются.
